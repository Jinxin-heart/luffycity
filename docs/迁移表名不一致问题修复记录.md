# Django 迁移表名不一致问题修复记录

## 一、问题背景

修改 `Banner` 模型的 `db_table` 属性（从 `fg_banner` 改为 `lf_banner`），重新执行迁移后，服务启动报错：

```
django.db.utils.ProgrammingError: (1146, "Table 'luffycity.fg_banner' doesn't exist")
```

## 二、错误原因分析

### 根本原因

Django 的 migration 系统依赖 `django_migrations` 表记录每次迁移的执行状态。当修改 `db_table` 后，数据库实际表名与 migration 记录不一致：

| 项目 | 状态 |
|------|------|
| `django_migrations` 中 `0002_banner` 记录 | 已执行（已标记） |
| 数据库中的实际表 | `lf_nav` 存在，`lf_banner` 不存在 |

### 为什么会这样

1. 最初 `Banner` 模型 `db_table = 'fg_banner'`，执行 migration 创建表
2. 后来修改了 `db_table = 'lf_banner'`，但**没有重新生成 migration**
3. 重新执行迁移时，Django 认为 `0002_banner` 已执行，不会再建表
4. 但服务访问时又去找 `fg_banner`，导致报错

## 三、修复过程

### 步骤 1：重置 migration 记录

```bash
# 将 home app 的所有 migration 标记为未执行（仅清除记录，不删除数据）
python manage.py migrate home zero --fake
```

> `--fake` 只更新 `django_migrations` 表中的记录，不执行实际的 DDL 操作。

### 步骤 2：标记已存在的表

```bash
# lf_nav 表已经存在，标记 0001 为已执行，跳过建表
python manage.py migrate home 0001 --fake
```

### 步骤 3：重新执行缺失的 migration

```bash
# 为 Banner 模型创建 lf_banner 表
python manage.py migrate home 0002
```

## 四、验证结果

```bash
python manage.py showmigrations home
```

输出：
```
home
 [X] 0001_initial
 [X] 0002_banner
```

两个 migration 均已成功执行，数据库表结构正确。

## 五、修改 db_table 后的正确操作顺序

> **以后每次修改模型 `db_table`，按以下步骤操作：**

```bash
# 1. 生成新的 migration（如果表名变了，需要重新生成）
python manage.py makemigrations <应用名>

# 2. 查看 migration 内容，确认 db_table 正确
python manage.py showmigrations <应用名>

# 3. 执行迁移
python manage.py migrate <应用名>

# 4. 验证
python manage.py showmigrations <应用名>
```

## 六、常见问题速查

| 现象 | 原因 | 解决方案 |
|------|------|----------|
| `Table 'xxx' doesn't exist` | migration 记录与实际不符 | `migrate 应用名 zero --fake` 再重做 |
| `Table 'xxx' already exists` | 表已存在但 migration 未标记 | `migrate 应用名 migration名 --fake` |
| `Missing Meta.model attribute` | Serializer 中写错 `models` 应为 `model` | 检查 `class Meta` 中的属性名 |

## 七、相关命令速记

```bash
# 查看 app 迁移状态
python manage.py showmigrations <应用名>

# 查看具体 migration 内容
python manage.py sqlmigrate <应用名> <migration名>

# 撤销迁移（不删除数据）
python manage.py migrate <应用名> zero --fake

# 撤销迁移并执行（删除表）
python manage.py migrate <应用名> zero
```
